| Store in MongoDB                | Store in AWS Secrets Manager     |
| ------------------------------- | -------------------------------- |
| Operator configuration          | API keys                         |
| Base URLs                       | Bearer tokens                    |
| Endpoints/paths                 | Username/password                |
| Payload templates               | HMAC secrets                     |
| Request/response mappings       | RabbitMQ passwords               |
| Timeouts                        | Kafka SASL credentials           |
| Feature flags/capabilities      | Client certificates/private keys |
| Secret references (`secretRef`) | Actual secret values             |
